# Assets

Every pixel in the game is generated by code. There are no downloaded, traced
or third-party assets, and no binary art in version control that nobody can
reproduce.

## The generator

`scripts/generate-assets.mjs` is a single dependency-free Node script (~2,900
lines). It writes real PNGs — chunk by chunk, with `zlib` from Node's standard
library — so `npm run assets` needs nothing installed.

```bash
npm run assets                     # write public/assets/**
node scripts/generate-assets.mjs --verify   # check integrity, write nothing
```

- **Deterministic.** One master seed (`0x5ec0a11d`) mixed with a hash of each
  asset's name through `mulberry32`. Re-running produces byte-identical files,
  so a diff in `public/assets/` always means a real change to the generator.
- **Manifest-driven.** The set of assets, their sizes, sprite-sheet frame
  layouts and animation frame counts are declared in
  `src/assets/assetManifest.ts`; the generator satisfies that manifest
  exactly, and a test fails the build if they diverge.

## What gets generated

68 PNGs under `public/assets/`:

| Group | Count | Contents |
| --- | --- | --- |
| `tiles/` | 26 | 13 terrain types × 2–4 variants (forest floor, grass, dirt, sand, mud, rock, mountain, water…) |
| `vegetation/` | 19 | oaks, pines, ferns, flowers, reeds, dead trees, stumps |
| `environment/` | 7 | rocks, logs, branches, nests, lily pads, fallen trees |
| `animals/` | 8 | deer, wolf, rabbit, squirrel, fox, eagle, songbird, fish (spritesheets) |
| `effects/` | 8 | flame sheet (4 frames), smoke puff, raindrop, snowflake, leaf, ember, ripple, splash |

Plus `favicon.svg`.

Art direction is enforced in code: a shared palette derived from the design
tokens in `src/index.css` (bark, moss, leaf, water, soil, parchment, danger) —
no gradients, no purple or indigo, and lucide-react for every UI icon.

## Placeholders

The game never depends on the generator having been run. `src/game/phaser/textures.ts`
checks each texture key at load time and, if one is missing, generates a flat
placeholder in the manifest's declared size and colour so the game stays
playable and reports which asset to produce. The one texture built on purpose
is `gen/terrain-atlas` — a runtime atlas stamped from the individual tile
textures, so terrain variants share one draw call.

## Licensing

All generated art is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), recorded in
`LICENSES/ASSET_LICENSES.md` with the generator, seed and command that
produced it. No third-party art is bundled.

## Adding art

1. Declare the asset in `src/assets/assetManifest.ts` (path, size, frame
   layout, states).
2. Add a generator function in `scripts/generate-assets.mjs` that draws into
   the canvas at the declared size, using the shared palette.
3. Run `npm run assets`, then `--verify`, then `npm test` — the manifest test
   asserts size and existence.
